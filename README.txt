SECUREBANK — ACADEMIC FRONTEND PROJECT
=====================================

HOW TO RUN
1. Extract the SecureBank folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. No installation or server is required for this frontend demo.
4. For the best development workflow, open the folder in Visual Studio Code.

PAGES
- index.html: Home
- about.html: Project overview
- login.html / register.html: Mock demo access
- dashboard.html: Sample dashboard and add demo transaction
- transactions.html: Transaction history
- fraud-detection.html: Rule-based demo risk checker
- security-center.html: Security awareness tips
- report-fraud.html: Demo incident report form
- admin.html: Admin preview

TECHNOLOGIES
HTML5, CSS3, Vanilla JavaScript, Browser LocalStorage.

IMPORTANT SAFETY NOTES
- This is a university/college demonstration only, not a real bank.
- Never enter real bank passwords, OTPs, card numbers, account numbers, or personal financial data.
- Login and registration are mock frontend flows. They do not provide real authentication.
- Fraud detection uses simple illustrative rules and is not a real fraud-detection engine.
- LocalStorage is not secure storage and must not be used for real banking data.
- Before any real deployment, build a secure backend with server-side authentication,
  password hashing, access controls, HTTPS, secure session management, validation,
  audit logging, database security, rate limiting, and professional security review.

SAMPLE DEMO LOGIN
Use any fictional email address and a demo password of at least 4 characters.
No real account is required.
