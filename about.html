Project Overview

About SecureBank

Smart Banking Security & Fraud Detection System

Problem Statement

As digital banking becomes more common, users need greater awareness of phishing, unusual transactions, and account security risks.

Project Objectives

  • Educate users about safer digital banking practices.
  • Demonstrate rule-based risk checks on sample transactions.
  • Provide an academic workflow for reporting suspicious activity.

Technology Stack

HTML5 CSS3 JavaScript LocalStorage

Future Scope

Future versions may add a secure backend, real authentication, a database, audit logs, and server-side risk analysis.

In this version, demo data is stored only in this browser.
